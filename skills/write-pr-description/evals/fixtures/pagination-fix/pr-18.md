# PR 18. Introduce continuation tokens

Archived PR for `src/entries/page.ts`. Its testing instructions used a disposable demo store:

1. Load the sample with `ledger demo load alternating-accounts`. In display order the entries are 101 (blue), 100 (red), and 99 (blue).
2. Run `ledger list --account blue --limit 1` and copy the token after entry 101.
3. Run `ledger list --cursor TOKEN --limit 1` to resume.
